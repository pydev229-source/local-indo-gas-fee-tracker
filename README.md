# Local Indo Gas Fee Tracker

Website dApp real-time Web3 Gas Tracker khusus komunitas Indonesia yang berjalan di atas Polygon Amoy Testnet.

## Fitur Utama:
- Real-time Gas Price (Gwei & Wei)
- Estimasi Biaya Transfer Native (MATIC) & ERC-20
- Pemantauan Blok Terakhir & Kepadatan Jaringan
- Antarmuka Modern & Responsif (Tailwind CSS)

## Deployment & Hosting Gratis:
Proyek ini siap di-deploy secara instan dan gratis menggunakan **GitHub Pages**, **Vercel**, atau **Netlify**.
